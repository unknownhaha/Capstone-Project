# Editor runbook — T13–T14

**ผู้ทดสอบ:** ผู้ร่วมงาน (editor) — บัญชีที่สอง  
**เจ้าของ:** ทำ T13 ก่อน แล้วส่งลิงก์เชิญ

บันทึก `session_id` แยก เช่น `E1-2026-06-01`

---

## ก่อนเริ่ม

- [ ] Owner สร้างโครงการและให้คะแนนบางส่วนแล้ว (ไม่บังคับ)  
- [ ] อีเมล editor ยังไม่เป็น member ของโครงการนี้  
- [ ] `npm run dev` + `.env` พร้อม

---

## T13 — เชิญและเข้าร่วม (ฝั่ง owner แล้ว editor)

### Owner

1. เปิดโครงการ → เมนูแชร์ / Share  
2. เปิด **collaboration**  
3. คัดลอกลิงก์เชิญ (`/join/[token]`)  
4. ส่งลิงก์ให้ editor (LINE / อีเมล)

### Editor

1. เปิดลิงก์ (ถ้ายังไม่ล็อกอิน → login แล้วกลับ join)  
2. ยอมรับคำเชิญ  
3. เปิดโครงการจากแดชบอร์ด  

**ผ่านเมื่อ:** editor เห็นโครงการ มีป้าย Shared with you

**เก็บหลักฐาน:** `POST /api/join/[token]`, ภาพหน้าจอแดชบอร์ด

---

## T14 — สิทธิ์ editor

1. ให้คะแนนอย่างน้อย 1 ข้อ  
2. ตรวจว่า **ไม่มี** kebab ลบ / แชร์ / อัปโหลดปกบนการ์ดโครงการ  
3. (ถ้ามีเวลา) owner ปิด collaboration หรือหมุนลิงก์ — editor เข้าไม่ได้ด้วยลิงก์เก่า  

**ผ่านเมื่อ:** แก้เกณฑ์ได้ จำกัดสิทธิ์ตาม `lib/project-access.ts`

**ทดสอบ 409 (ถ้ามีเวลา):** owner และ editor แก้เกณฑ์เดียวกันพร้อมกัน — ต้องมีข้อความชนกัน
