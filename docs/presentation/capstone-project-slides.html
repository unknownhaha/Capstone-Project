Building Accessibility Inspection App

Capstone Project — มยผ. 6301 (Inclusive Design)

Next.js 16 MongoDB NextAuth UploadThing

Purpose

  • Mobile-first web app for building accessibility inspections
  • Aligned with Thai public-sector standard มยผ. 6301
  • Targets inclusive design for people with disabilities and older adults
  • UI mix of English and Thai; standards content is primarily Thai

What Inspectors Can Do

  • Register and log in
  • Create projects (sites/buildings) with selected criteria groups
  • Score each criterion: 0 / 1 / 2, notes, inspection photos
  • View reference figures from the official standard (PDF diagrams)
  • Track completion % per project
  • Collaborate via invite links (shared editor access)

Domain Model — User

  • firstName, lastName, hashed password
  • contact.email — unique, used for login
  • profileImg — UploadThing URL
  • Optional organization, project refs

Domain Model — Project

  • userId — owner (never transferred)
  • members[] — editors joined via invite token
  • sections[] → groups → criteria[]
  • Each criterion: score (0|1|2|null), note, imgs[]
  • Pre-save hook recalculates completionRate

Catalog reference images ≠ user inspection photos

Standards Catalog

  • 8 main JSON files → STANDARDS_CATALOG
  • Items: item_id, display_text, source_text, notes
  • Reference images from JSON or figure-map.json via source_clause
  • Lookups: findCatalogItem, findCatalogGroup, findCatalogSection

Main User Flow

Login / Register → All Projects (/allproject)

↓ Create project (select criteria groups) → POST /api/project

↓ Section picker → Criteria checklist

↓ Score, notes, photos + reference image (ภาพอ้างอิง)

Share: owner enables collaboration → copy /join/[token]
